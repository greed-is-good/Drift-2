# Drift

**Drift** — приложение для друзей: чат, голосовые каналы и демонстрация экрана **без постоянного сервера в облаке**.

Создатель — **ASMAXI**. Текущая версия — **0.10.8**.

---

## Зачем это нужно

Обычные мессенджеры держат ваши сообщения на чужих серверах. В Drift комната живёт **на компьютерах участников**: один из вас временно становится «хостом» (координатором), остальные подключаются к нему. Если хост вышел — роль может перейти к другому (поэтому название *Drift* — «дрейф»).

Пока онлайн хотя бы один участник с рабочим Drift на ПК, комната может оставаться доступной.

---

## Что умеет

- Текстовые каналы (сообщения, реакции, картинки)
- Голосовые каналы (как в Discord)
- Демонстрация экрана
- Приглашение по ссылке
- Голосование за кик участника (`/votekick`)
- Команды чата: `/roll`, `/писиюндрик`, `/help`
- Автообновление из Настроек
- Темы оформления, звуки, оверлей голоса

---

## Как это работает (простыми словами)

1. Вы создаёте комнату на своём ПК.
2. Drift поднимает **безопасный туннель в интернет** (Cloudflare) — друзьям не нужно быть в одной Wi‑Fi сети.
3. Вы копируете **ссылку-приглашение** и отправляете друзьям.
4. Друзья открывают ссылку → запускается Drift → они заходят в комнату.
5. Текст идёт через хоста-координатора; **голос** идёт напрямую между участниками (WebRTC).

Если вы выключили ПК, а у друзей Drift открыт и есть публичный туннель — кто-то из них может стать новым хостом, и остальные переподключатся сами (нужна свежая сборка у всех).

## Быстрый старт

1. Установите Drift на Windows (файл из [Releases](https://github.com/asmaxi/p2pchat/releases)).
2. Укажите **имя** (без имени войти нельзя).
3. Нажмите **Создать комнату** и подождите, пока поднимется туннель (первый раз может скачать вспомогательную программу `cloudflared`).
4. **Пригласить** → скопируйте ссылку другу.
5. Друг открывает ссылку → «Открыть Drift» → заходит в комнату.
6. Для разговора зайдите в **голосовой канал**.

Если туннель не поднялся: **Настройки → Поднять / обновить туннель**, затем снова скопируйте приглашение.

---

## Полезные советы

| Ситуация | Что делать |
|---|---|
| Друг не может зайти | Пришлите **свежую** ссылку из «Пригласить» (старый Cloudflare-адрес мог устареть) |
| Нет голоса между разными сетями | Подождите соединение; при проблемах — Настройки → Сеть (TURN / Metered) |
| Хост вышел, комната «умерла» | Нужен ещё хотя бы один desktop с рабочим туннелем |
| Крестик окна | Сворачивает в трей; полный выход — ПКМ по иконке → **Выход** |
| Обновление | Настройки → **Проверить обновления** → установить |
| Баг / нет голоса | Диагностика → **Временные логи** → скачать `.txt` и прислать |

## Удаление (Windows)

При полном удалении (не при обновлении) чистятся только данные Drift:  
`%AppData%\com.p2pchat.desktop`, `%LocalAppData%\com.p2pchat.desktop`, кэш обновлений, автозапуск и схемы `drift://` / `p2pchat://`. Чужие папки не трогаются.

## Для разработчиков

```bash
pnpm install
pnpm run test
cd artifacts/p2pchat && pnpm desktop:dev
```

**Релиз:** поднять версию в `artifacts/p2pchat` (`package.json`, `tauri.conf.json`, `Cargo.toml`, `app-update.ts`) →  
`git tag v0.10.8 && git push origin v0.10.8` — GitHub Actions соберёт установщик.

Опционально стабильный TURN для голоса между разными сетями: [metered.ca](https://www.metered.ca/) API key → Настройки → Сеть, или свой coturn.

```
lib/p2p-*              # identity, protocol, room session
artifacts/api-server   # опциональный bootstrap
artifacts/p2pchat      # UI + Tauri (local hub + tunnel)
```
